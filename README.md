# Практическая работа №3

## Цель

Разобраться, как числа типа int и текстовые строки превращаются в байты, понять влияние кодировок и порядка байтов (little-endian) на хранение данных

## 1. Представление числа в байтах

1: 01-00-00-00
256: 00-01-00-00
65536: 00-00-01-00

1. Потому что числа в типе данных int если переводить в байты, он всегда будет содержать 4 байта
2. Байты числа (01-00-00-00 -> 00-01-00-00)
3. Потому что выходит за лимит шестнадцатеричного кода (FF - максимум для байта)

## 2. Порядок байтов

BitConverter.IsLittleEndian : True
Байты числа: 78-56-34-12
Потому что little-endian хранит младшие байты первыми

## 3. Текст и UTF-8

Потому что русские символы занимают по 2 байта, в то время как английские занимают по 1 байту, т.е. разные символы из разных языков могут содержать свое кол-во байтов.

## 4. Английская и русская буква

Eng A = 41
Rus A = D0-90
У разной кириллицы есть свое необходимое кол-во байтов

## 5. Обратное преобразование

Потому что UTF-8 может преобразовать из строки в байты и из байтов в строку, т.е. UTF-8 служит неким переводчиком.

1. Байты - последовательность 0 и 1, 1 байт = 8 бит
2. Потому что он использует шестнадцатеричный код
3. Перевод из числа/строки в байты
4. Используется ли в компьютере little-endian
5. Потому что little-endian хранит байты по возрастанию
6. Потому что разные символы из разных языков могут содержать свое кол-во байтов.
7. Перевод из числа/строки в байты с обращением к UTF-8
8. Потому что UTF-8 участвует как переводчик между числом/строкой и байтами
9. Потому что каждая программа по разному знает как интерпретировать байты
10. Числа в памяти представлены в виде байтов
